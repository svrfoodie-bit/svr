## What it is
Single-tenant business management app for a cashew processing unit: raw purchases, workers/payroll,
production, sales, accounting, exports, plus the CashewFlowX stock module and a Lead Manager.
Express 4 REST API (`backend/`, ~30 controllers / 38 models, raw SQL on MySQL) + React 18/Vite SPA
(`frontend/`, ~80 pages). Standalone app — no other services in an estate.

**Deploy:** frontend → Netlify (`netlify.toml:1-4`, SPA redirect). Backend → Render, DB → Aiven
MySQL 8 (not in repo — Render build command runs migrations; inferred from team notes, confirm).

## Request pipeline (all modules) — `backend/src/server.js`
`trust proxy 1` (`:20`) → helmet/compression (`:25-26`) → CORS allowlist from `ALLOWED_ORIGINS`, localhost always allowed (`:54`)
→ json/urlencoded (`:56-57`) → morgan→winston (`:60`) → rate limits: login 20/15 min (`:82`), `/api/v1` 500/15 min (`:83`)
→ routers (`:117-123`) → `notFound` + `errorHandler` (`:126-127`). Boot: DB test → `seedDemoUsers()` (`:141`) → listen :5000 → scheduler unless `ENABLE_SCHEDULER=false`.

Frontend: `frontend/src/main.jsx` (BrowserRouter, QueryClient) → `frontend/src/App.jsx` routes under `MainLayout` + `ProtectedRoute`;
axios `frontend/src/services/api.js:9` (base `VITE_API_BASE_URL` or `http://localhost:5000/api/v1`, 10 s timeout, Bearer from `authStore`, 401 → logout).
Vite dev proxies `/api` → :5000 (`frontend/vite.config.js:8`).

## Data & persistence (the #1 gotcha)
- **Engine:** MySQL 8 in prod (Aiven, strict mode), MariaDB locally. SQL must run on both.
- **Access:** raw SQL via one `mysql2` pool, `backend/src/config/database.js:21`; SSL only when `NODE_ENV=production` (`backend/src/config/database.js:28`).
- **Two schema paths:** `backend/create-tables.js` (`npm run setup-db`, fresh bootstrap of core tables) and
  `backend/migrations/001…014` via `backend/scripts/migrate.js` (`npm run migrate`, `schema_migrations` table,
  refuses non-localhost without `--yes`, portable DDL via `backend/src/utils/schemaHelpers.js:93`).
  A fresh DB needs both; legacy one-off scripts (`run-*-migration.js`, `create-*-tables.js`) predate the runner.
- No tenancy column; single business. Soft delete via `isDeleted` on master data.

## Cross-cutting
- **Errors:** central `backend/src/middleware/errorHandler.js`; envelope `{ success, data | message }`.
- **Auth:** in-app JWT (`backend/src/middleware/auth.js:16`); no role enforcement (`authorize` unused).
- **Audit:** `autoAudit('<table>')` route middleware (`backend/src/middleware/auditMiddleware.js`).
- **Config:** dotenv; see `backend/.env.example`, `frontend/.env.example`.
