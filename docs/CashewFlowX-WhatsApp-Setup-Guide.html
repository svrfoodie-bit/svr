How it works in one line: CashewFlowX sends a WhatsApp message to the customer whenever stock is given or a payment is received, through Meta's official WhatsApp Cloud API. Meta only allows pre-approved message wording ("templates"), and charges per message.

1 What you need before starting · 5 min

  1. Your personal Facebook account. Meta business accounts are created under a real person's login. Customers never see your personal profile.
  2. One business document for verification, any one of:
    • GST certificate
    • Udyam / MSME registration
    • Shop & Establishment licence
    • PAN / incorporation certificate (for a company)
  3. A business email address. Gmail works; an email on your own domain makes verification easier.
  4. A debit/credit card. Needed only when going live (Part 9).
  5. A computer. Meta's setup screens are much easier on a laptop than on a phone.

2 Create the Meta Business account · 10 min

Meta calls this a "business portfolio".

  1. Open business.facebook.com and log in with your Facebook account.
  2. Click Create an account. If an account already exists, it is listed; just open it.
  3. Enter the business name exactly as on your GST/Udyam document (e.g. SVR Food Production), your name and business email.
  4. Open the confirmation email from Meta and click the link.

3 Start business verification · 15 min + waiting

Start this early. It can be approved in minutes or take a few days. You can continue with Part 4 while it is under review.

  1. In business.facebook.com open Settings (gear icon) → Business info (sometimes under Security Centre) → Start verification.
  2. Enter the legal business name, address, phone and website (if any). Everything must match your document exactly, including spelling and address format.
  3. Upload your GST or Udyam certificate.
  4. Confirm with the code Meta sends (email or phone).
Until verification is approved, Meta limits how many customers you can message per day. Testing works fine in the meantime.

4 Become a developer and create the app · 10 min

  1. Open developers.facebook.com → Get Started. Accept the terms and verify your mobile with the code. (This only proves you are a real person; it is not the business number.)
  2. Go to My Apps → Create App.
  3. App name: CashewFlowX. Contact email: yours.
  4. Use case: choose "Connect with customers through WhatsApp" → Next.
  5. Business portfolio: select the one from Part 2.
  6. Click Create app. Meta automatically creates a WhatsApp Business Account and gives you a free test phone number.

5 Send your first test message · 5 min

  1. In your app's left menu: WhatsApp → API Setup.
  2. Under "From" (Meta's test number), copy the Phone number ID. It is a long number such as 106540352242922, not the phone number itself.
  3. Click Generate next to Temporary access token and copy it. It stops working after 24 hours, which is fine for testing.
  4. Under "To" → Manage phone number list, add your own mobile and enter the code WhatsApp sends you. The test number can only message up to 5 numbers verified this way.
  5. Open CashewFlowX (nut icon in the header) → WhatsApp:
    • Paste the Phone Number ID
    • Paste the Access Token
    • Click Save Settings
  6. In Send a test message, enter your mobile → Send Test. You should receive Meta's "Hello World" message on WhatsApp. If it arrives, the connection works.

6 Create the message templates · 30 min + approval

Two templates, each in English and Telugu: four approvals in total. The names and texts must be exactly as below, because CashewFlowX fills in the {{1}}, {{2}}… values in this order.

Before submitting: have a Telugu speaker read the Telugu texts. They were written by the developer and may need wording fixes. If you change the wording, keep every {{n}} with the same number and meaning.
  1. Open business.facebook.com → WhatsApp Manager → Message templates → Create template.
  2. Category: Utility (not Marketing). Name: copy from the card below. Language: plain English (not "English (US)"; CashewFlowX uses the code en). If asked for the type of variable, choose Number.
  3. Paste the English body, fill in the sample values from the table, and Submit.
  4. On the same template choose Add language → Telugu → paste the Telugu body → same samples (use the Telugu balance sample) → Submit.
  5. Repeat steps 1–4 for the second template.
  6. Wait for status Active (usually minutes to a day). If one is rejected, see Troubleshooting.

7 Create the permanent access token · 10 min

The 24-hour token from Part 5 is for testing only. CashewFlowX needs one that never expires.

  1. business.facebook.com → Settings → Users → System users → Add.
  2. Name: cashewflowx-server, role Admin → Create.
  3. Select it → Assign assets → Apps → your CashewFlowX app → Full control → Save.
  4. Assign assets again → WhatsApp accounts → your WhatsApp account → Full control → Save.
  5. Click Generate token → choose your app → Expiration: Never → tick both permissions:
    • whatsapp_business_messaging
    • whatsapp_business_management
  6. Generate → copy the token immediately. Meta never shows it again.
  7. Paste it into CashewFlowX → WhatsApp → Access Token → Save Settings. The screen will then only show its last 4 characters.
Treat this token like a password. Don't send it over WhatsApp or email, and don't share screenshots of it. If it leaks, delete it under System users and generate a new one, then save the new one in CashewFlowX.

8 Add the new business number · when the SIM arrives · 10 min

Don't install WhatsApp on the new SIM. A brand-new number goes straight onto the API. A number already on the WhatsApp Business app can be connected with Meta's "coexistence" option instead, but a number on normal personal WhatsApp cannot be used.
  1. Put the SIM in any phone that can receive SMS or calls.
  2. WhatsApp Manager → Phone numbers → Add phone number.
  3. Display name: your business name, e.g. SVR Food Production. Meta reviews it, and it must match your business.
  4. Enter the number → verify with the SMS or voice code.
  5. Copy the new Phone number ID → paste it into CashewFlowX in place of the test one → Save Settings.

9 Go live · 10 min

  1. WhatsApp Manager → Payment settings → add your card. Meta won't send real business messages without it.
  2. CashewFlowX → WhatsApp → Send Test to your mobile. It should arrive from the new number.
  3. Check Business name in messages is filled in, then turn WhatsApp messages ON → Save Settings.
  4. Add yourself as a test customer (tick Send WhatsApp updates, choose a language), add a small stock entry, and check the message arrives. Then try Telugu. Delete the test entries afterwards.
  5. For each real customer: open Edit, confirm the mobile number, set the language, and tick Send WhatsApp updates only if they agreed to receive messages.
After every stock or payment save, CashewFlowX shows "WhatsApp message sent" or the exact reason it failed. Each customer's WhatsApp tab lists all messages, with Resend for failed ones.

Troubleshooting

CashewFlowX shows Meta's error message, usually with a code like [code 132001]. Common ones:

What you seeWhat it meansFix
Invalid OAuth access token [code 190]Token expired or wrong. The temporary token lasts only 24 hours.Create the permanent token (Part 7) and save it again.
Recipient phone number not in allowed list [code 131030]You are still on Meta's test number, which only messages verified numbers.Add the customer's number under API Setup → "To", or finish Part 8.
Template name does not exist in the translation [code 132001]Template name or language does not match an approved template.Check spelling in CashewFlowX settings, that the template is Active in that language, and the language codes (en / te).
Number of parameters does not match [code 132000]The approved template has a different number of {{n}} than expected.Re-create the template using the exact text in Part 6.
Message undeliverable [code 131026]The customer's number is not on WhatsApp, or is wrong.Check the customer's mobile number.
Business eligibility / payment issue [code 131042]No valid payment method on the WhatsApp account.Add a card under Payment settings (Part 9).
Phone number not registered [code 133010]The business number was added but not fully registered.Finish verification of the number in WhatsApp Manager.
WhatsApp Phone Number ID or Access Token is not setCashewFlowX settings are incomplete.Fill both fields and save.
Customer has no valid mobile numberThe customer's mobile is empty or not 10 digits.Edit the customer and fix the number, then Resend.
WhatsApp API did not respond in timeTemporary network problem.Use Resend on the customer's WhatsApp tab.
Template rejected? Usual reasons: chose "Marketing" instead of "Utility"; text starts or ends with a variable; missing sample values; or promotional words. Fix and resubmit. The texts above already follow Meta's rules.

Questions

How much does it cost?

Meta charges per message in the "Utility" category. Rates change and differ by country, so check the current India rate in WhatsApp Manager → Payment settings / pricing. CashewFlowX itself has no extra charge.

Can I edit the message wording?

Only in Meta (WhatsApp Manager → Message templates), and every change is reviewed again. Keep the same {{n}} numbers and meaning, or CashewFlowX will fill in the wrong values.

Why does an edited or deleted entry not send a message?

By design: edits and deletes are usually your own corrections, and messages about them would confuse customers. Only new stock and new payments send messages.

Can I keep chatting with customers from my phone?

A number used only by the API has no WhatsApp app. If you want to chat from the app on the same number, connect an existing WhatsApp Business app number using Meta's "coexistence" option instead of a fresh SIM.

Do I see "delivered" and "read" ticks in CashewFlowX?

Not yet. "Sent" means Meta accepted the message. Delivery/read status needs Meta to call back into the server (a webhook), which can be added later.

Where is the access token stored?

On the server, in the CashewFlowX WhatsApp settings table. It is never sent back to the browser; the screen shows only its last 4 characters.

Meta's screens look different from this guide.

Meta renames menus from time to time. Look for the same words (System users, Message templates, API Setup, Phone numbers) using the search in business.facebook.com or developers.facebook.com.

CashewFlowX WhatsApp settings: CashewFlowX (nut icon in the header) → WhatsApp.
